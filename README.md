# SmartBill - 帳票管理システム

## プロジェクト概要
- **名前**: SmartBill
- **目的**: 見積書・納品書・請求書の作成・管理を効率化する帳票管理システム
- **主な機能**: 見積→納品→請求の一連の業務フローを実現

## 実装済み機能

### 見積データ入力 (`/estimates`)
- 見積書のCRUD操作（新規作成・編集・複製・削除）
- 得意先サジェスト検索
- 明細の追加・編集・削除・ドラッグ&ドロップ並び替え
- 上代/下代表示切替（見積書のみ対応）
- 小計・消費税・合計の自動計算
- ステータス管理（作成中・未送付・送付済・受注・失注）
- 年月フィルター・テキスト検索
- 最後に選んだ得意先を記憶

### 納品データ入力 (`/deliveries`)
- 納品書のCRUD操作
- 見積から納品書への変換機能
- 得意先サジェスト検索
- 明細の追加・編集・削除・ドラッグ&ドロップ並び替え
- 小計・消費税・合計の自動計算
- ステータス管理（作成中・未送付・納品済・請求済）
- 年月フィルター・テキスト検索
- 最後に選んだ得意先を記憶

### 請求書作成 (`/invoices`)
- 請求書のCRUD操作
- 納品書から請求書への変換機能（複数納品書を集約可能）
- 締め日に基づく請求期間の自動計算
- 得意先サジェスト検索
- 明細の追加・編集・削除・ドラッグ&ドロップ並び替え
- 小計・消費税・合計の自動計算
- 振込先口座の選択
- 支払期限の設定
- ステータス管理（作成中・未送付・送付済・入金済・支払遅延）
- 年月フィルター・テキスト検索
- 最後に選んだ得意先を記憶

### マスタ管理
- **取引先マスタ**: 取引先情報、締日・支払日設定
- **商品マスタ**: 商品情報、単価、税率設定
- **分類マスタ**: 商品カテゴリ管理
- **自社情報**: 会社情報、銀行口座（複数口座対応）、ロゴ・印影

### ダッシュボード (`/`)
- 今月の売上表示
- 未請求納品書数
- 取引先数
- 取引先別売上（今月）

### 共通機能
- 2カラムUI（サイドバー折りたたみ対応）
- 編集中の離脱警告
- キーボードショートカット（Ctrl+S: 保存、Esc: キャンセル）
- 成功ダイアログ

## データアーキテクチャ

### データモデル
- **clients**: 取引先マスタ（締日・支払日含む）
- **products**: 商品マスタ
- **categories**: 商品カテゴリ
- **estimates / estimate_items**: 見積書・明細
- **deliveries / delivery_items**: 納品書・明細
- **invoices / invoice_items**: 請求書・明細
- **company_info**: 自社情報

### ストレージサービス
- **Cloudflare D1**: SQLiteベースのリレーショナルデータベース

## 使用方法

### 基本フロー
1. **見積作成**: `/estimates` で見積書を作成
2. **受注**: 見積書のステータスを「受注」に変更
3. **納品書作成**: `/deliveries` で「見積から作成」ボタンから納品書を作成
4. **納品済に変更**: 納品書のステータスを「納品済」に変更
5. **請求書作成**: `/invoices` で「納品書から作成」ボタンから請求書を作成（締め日で自動フィルタリング）
6. **入金確認**: 請求書のステータスを「入金済」に変更

### 締め日処理
- 取引先マスタで締め日を設定（末締め、20日締めなど）
- 請求書作成時に締め日に基づいて自動的に請求期間が計算される
- 請求期間内の納品済み納品書を自動で取得
